# Download speed

Небольшой скрипт на Node.js для проверки скорости скачивания.

Он отправляет 10 запросов к указанному адресу по очереди, скачивает ответы и показывает среднее время запроса, общий объём данных и скорость в Мбит/с.

```bash
node index.ts [file]
```

Укажите адрес файла, который можно скачать.
